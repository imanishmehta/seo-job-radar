Optional Google API

Only needed for automated search suggestions. Serper is a separate service with limited trial credits and paid usage afterwards. Leave it disabled for the free-only setup.

  1. Open GitHub secrets, select New repository secret, name it SERPER_API_KEY, and paste your key there.
  2. Only if you want API usage, add a repository variable named ENABLE_GOOGLE_DISCOVERY with value true.
  3. Run a fresh crawl. Verified company career pages are added automatically (up to 3 per run). Pages with unclear ownership or home country stay in review.
